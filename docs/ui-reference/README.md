# Style references

Style only; do not copy illustrations, currencies, offers or monetization.
Use native fonts and theme primitives; UIKits is an optional editor reference.

- `shop_ui_featured.png`: broad bright-green header, thick charcoal outline, white chunky title with black text stroke, red square close button, dark inset cards.
- `shop_ui_money.png`: three evenly spaced green gradient cards, large centered readable numbers, dark card borders, bright action rows.
- `shop_ui_speed.png`: cyan section heading, wide horizontal offer panels, oversized bubbly labels, green primary actions, generous spacing.
- `shop_ui_speed2.png`: consistent grid card borders and gutters, blue gradient fill, white outlined numbers with green/gold accents.
- `index_ui.png`: bright green header, translucent dark collection cards, large colorful category buttons, bold income labels, explicit selection footer.
- `shop_icon.png`: wide lime button, white label/icon with a heavy dark outline and thin light inner border; readable at small size.
- `index_icon.png`: same button proportions and outline language, cyan semantic color and bold white label.
- `Screenshot 2026-09-14 232559.png`: red header/close action, dark inset status sections, large outlined numeric progress, clear separated primary action.

Translate the reference outline weight to UITheme strokes around3px at the
1280x720 design size, use FredokaOne/LuckiestGuy built-in fonts, rounded chunky
panels, saturated semantic palette and >=44px touch targets. Do not reproduce
the realistic creatures shown in the reference artwork.
